Why R4SUB?

Submission readiness is more than validation reports. It's an evidence graph across datasets, metadata, traceability, and reviewer experience.

📊

Evidence-Based Scoring

Normalize heterogeneous sources (Pinnacle21, OpenCDISC, internal engines) into a unified evidence table. Transparent, reproducible scoring primitives.

🔍

Transparent & Auditable

No black-box algorithms. Every weight, threshold, and aggregation method is configurable and documented. Full traceability from raw input to final score.

🧩

Modular Ecosystem

Core contracts separate from domain logic. Mix and match packages for quality, traceability, risk, and usability assessment.

🛠️

Tool-Agnostic

Built to integrate with your existing validation infrastructure. Parsers for common tools, extensible for proprietary systems.

Get Started

Install r4subcore and start assessing your submission in minutes

1. Installation

# Install from GitHub (CRAN submission planned)
# install.packages("pak")
pak::pak("R4SUB/r4subcore")

2. Create a Run Context

library(r4subcore)

ctx <- r4sub_run_context(
  study_id = "STUDY001",
  environment = "PROD"
)

ctx$run_id  # Unique identifier for this assessment

3. Ingest Validation Results

# Parse Pinnacle21 output
p21_data <- read.csv("pinnacle21_report.csv")

evidence <- p21_to_evidence(
  p21_data,
  ctx = ctx,
  source_version = "P21-3.1"
)

# View summary
evidence_summary(evidence)

4. Score and Analyze

# Aggregate by indicator
scores <- aggregate_indicator_score(
  evidence,
  by = "indicator_id",
  method = "weighted"
)

# View worst performers
head(scores[order(scores$score), ])
